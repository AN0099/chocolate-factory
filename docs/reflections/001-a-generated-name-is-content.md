# 001: a generated name is content

**Row:** `AGENTS.md`, "Hard rules", rule 1, at commit `71bbc5e`.

**Records:** on 2026-10-22 a HumanLayer task branch, named automatically from the opening words of the request that started the task, was pushed and published. Copies of public push events persist outside GitHub, so deleting the branch does not take the name back. The rule now requires chosen names and enforces them at five layers.

**Lesson:** Any identifier a tool derives from a request is published content, and gets the same review as the content before it can leave the machine.

**Supersedes:** none.

**Filed:** 2026-10-24.
