# Reflections

A reflection entry is a bounded record about one row already published in this repository: what the row records, and the lesson as one sentence shaped as a rule. The format is toothpaste-kit's, unchanged: [`toothpaste-kit/docs/reflections/README.md`](../../toothpaste-kit/docs/reflections/README.md).

Each entry is one file, `NNN-short-slug.md`, with exactly these fields: **Row** (file and row, pinned at a commit), **Records**, **Lesson**, **Supersedes**, **Filed**. An entry is never edited after filing; a correction is a new entry that supersedes it. An entry holds no session content and nothing the row does not support.
